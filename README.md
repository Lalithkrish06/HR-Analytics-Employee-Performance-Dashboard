# Employee Performance & Salary Dashboard (Excel)

An interactive Excel dashboard that analyzes employee performance ratings, salaries, and department-wise metrics across a 30-person organization using PivotTables, PivotCharts, and slicers.

## 📊 Overview

This project takes a raw employee dataset (ID, department, designation, salary, location, performance rating, active status) and turns it into an interactive dashboard for HR-style analysis — department comparisons, salary distribution, performance by designation, and headcount summaries.

## 🔑 Key Features

- **Interactive slicers** to filter by department, location, and designation
- **PivotTables** summarizing salary and performance by department, location, and employee
- **PivotCharts** visualizing performance ratings and salary distribution
- **Department Summary sheet** with average salary, total salary, and headcount per department
- Clean, multi-sheet structure separating raw data from analysis views

## 🗂️ Sheets Included

| Sheet | Purpose |
|---|---|
| `Employee_List` | Raw source data (30 employees) |
| `SALARY DASHBOARD` | Main interactive dashboard with charts & slicers |
| `TOTAL PERFORMANCE` | Performance rating breakdown by department |
| `PERFORMANCE RATING` | Employee-level performance by department |
| `LOCATION` | Salary breakdown by location & department |
| `SALARY OF EMP` | Salary and performance per employee |
| `COUNT ACTIVE` | Active employee count |
| `Department_Summary` | Avg/Total salary and headcount by department |

## 🛠️ Tools Used

## 🚀 How to Use

1. Download the `.xlsx` file
2. Open in Microsoft Excel (2016 or later recommended for full slicer/timeline support)
3. Go to the `SALARY DASHBOARD` sheet
4. Use the slicers to filter by department, location, or designation
