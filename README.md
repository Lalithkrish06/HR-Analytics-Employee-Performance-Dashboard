## 🚀 Project Overview

**HRInsight 360** is an interactive **HR Analytics Dashboard** developed using Microsoft Excel to transform raw employee data into meaningful business intelligence.

The dashboard uses **PivotTables, PivotCharts, Slicers, Excel functions, and data analysis techniques** to provide a structured view of employee performance, compensation, workforce distribution, and department-level metrics.

It is designed to support **data-driven HR decision-making** by making important workforce information easier to analyze and interpret.

---

## 🎯 Business Objective

The primary objective of **HRInsight 360** is to convert raw employee information into actionable HR insights.

### Key Objectives

- 📊 Analyze employee performance trends
- 💰 Compare salary distribution across departments
- 👥 Track workforce strength and active employees
- 🏆 Identify top-performing roles and departments
- 📈 Generate department-level KPIs
- 💡 Convert raw HR data into meaningful business insights

## 📂 Workbook Structure

| Sheet Name | Description |
|---|---|
| `Employee_List` | Raw employee dataset |
| `SALARY DASHBOARD` | Main HR analytics dashboard |
| `TOTAL PERFORMANCE` | Department performance analysis |
| `PERFORMANCE RATING` | Employee performance insights |
| `LOCATION` | Location-wise salary analytics |
| `SALARY OF EMP` | Individual employee salary report |
| `COUNT ACTIVE` | Active employee tracking |
| `Department_Summary` | Department-level KPIs |
